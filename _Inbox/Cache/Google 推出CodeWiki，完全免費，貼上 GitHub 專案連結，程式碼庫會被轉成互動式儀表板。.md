
Google 剛剛推出了一個超實用的新工具，叫 CodeWiki。
它完全免費，只要貼上一個 GitHub 專案連結，下一秒，整個程式碼庫就會被轉成 互動式儀表板。
 用簡單步驟告訴你：這段在幹嘛、為什麼要這樣寫。
更誇張的是，它還會出現 教學影片，
 直接講解程式裡的關鍵技巧，非常適合快速學習或回顧。
而且裡面內建一個 AI 聊天機器人，
 你可以直接問它：「這個 function 是做什麼的？」

使用方式也超簡單：
 打開 CodeWiki → 貼上 GitHub Repo URL → 完成。
它可以處理 高達 140 萬行程式碼，
 而且原始碼有更新時，分析內容也會自動同步更新。

你可以獲得的功能包括：
 ✔ 視覺化架構圖與流程圖
 ✔ 清楚的程式碼拆解說明
 ✔ 即時 AI 問答
 ✔ 自動同步最新程式碼
目前僅支援開源專案，但是 完全免費的公開測試版。
