進階玩家方案：Scrcpy (電腦控制手機錄音)
​如果你熟悉 Python 和自動化（如你提到的 n8n 工作流），這招是神級方案，因為它能讓你直接在電腦上錄製手機的聲音：
​工具：安裝開源軟體 Scrcpy。
​功能：它能透過 USB 線將手機畫面與聲音「即時串流」到電腦。
​優勢：
​你可以直接在電腦端用 OBS 或 Audacity 錄製手機傳過來的數位音訊。
​自動化潛力：你可以寫 Python 腳本，透過 ADB 指令自動在手機豆包貼上文案、點擊播放，同時在電腦端自動開啟錄音。這能完美解決「豆包網頁版沒聲音」的問題。

​方案 D：修改 F12 抓取策略 (進階過濾)
​如果一定要用 F12，不能搜尋 mp3，要搜尋 blob 或 msc。
​打開 F12 -> Network。
​在 Filter 框輸入：is:media-stream 或 Fetch/XHR。
​找類型（Type）為 fetch 或 websocket 的請求。
