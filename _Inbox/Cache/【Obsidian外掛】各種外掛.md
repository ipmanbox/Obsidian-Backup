●Hybrid Git Sync
设计理念与核心优势
由于不同操作系统的底层限制与网络环境差异，在多端使用 Git 管理 Obsidian 笔记往往需要不同的同步策略。Hybrid Git Sync 采用创新的自适应智能引擎，旨在为电脑端和手机端搭建一座平滑、无缝的同步桥梁。

本插件不会一刀切地在所有平台上运行相同的底层逻辑，而是根据您当前的使用环境，智能分配同步工作负载：

https://github.com/wk-obsidian/HybridGitSync/blob/main/README_ZH.md




●Direct Git Sync
直接 Git 同步
在桌面和行動裝置上，將您的 Obsidian 保險庫直接與私人 GitHub 儲存庫同步。

端對端操作：開啟設置，新增您的儲存庫 URL 和令牌，儲存，然後同步。

Direct Git Sync 專為希望實現基於 Git 的簡單 Vault 同步，而無需在每台裝置上安裝 Git 的使用者而設計。它使用isomorphic-gitObsidian 相容的 HTTP 請求進行倉庫操作，因此相同的流程可以在桌面版和行動版 Obsidian 中運行。
https://github.com/swekizer/Direct-Git-Sync
