賣電影票的集點卡優惠價語法，總整理:

例如:
>>>age = 35
>>>pointcard = True
>>>count = 4
>>>if (age < 18): <-先判斷是小於18歲，不賣票。
>>>    print('不賣票')
>>>elif (60 <= age): <-再判斷是否大於、等於60歲，有優惠價。
>>>    print('票價為200元')
>>>elif ((pointcard == True) and (count >= 5)): <-再同時判斷是否有集點卡和累積5點次數。
>>>    print('票價為200元')
>>>else: 
>>>    print('票價為400元')
>>>票價為400元
