注意if[語法正確，但邏輯順序錯誤]的問題

if的程式判斷方式是由上而下，依序執行。
若是一開始就判斷年齡超過18歲(滿足判斷條件)，判斷為true。就會直接輸出'票價為400元'。
後面的程式，就不會繼續判斷了。

順序錯誤的程式:

age = 70
if (18 <= age): <-會先判斷是否18歲(包含)以上
    print('票價為400元')
elif (60 <= age):<-再判斷是否60歲(包含)以上
    print('票價為200元')
else:
    print('不賣票')

票價為400元


可以將語法順序修改成以下這樣:

age = 70
if (18 <= age <= 59):
    print('票價為400元')
elif (60 <= age):
    print('票價為200元')
else:
    print('不賣票')
    
票價為200元
