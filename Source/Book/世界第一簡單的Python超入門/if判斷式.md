使用if判斷式的時候，在語法中必須使用縮排。
語法中，按［tab］一次，可以向右縮排。
或者是按 ［空白鍵］四次，兩種方式都可以，但不要混著用。

其他不屬於if判斷式的語法，則不需要使用縮排，否則會出錯。

>>>age = 28
>>>if (18 <= age):
            print('賣票給他')
>>>賣票給他 ＜--執行結果



如果想讓 if 多做一些事情，例如[如果...就...否則就...]可以加上 else 關鍵字。



>>>age = 15
>>>if (18 <= age):
            print('賣票給他')
>>>else:
>>>    print('不賣票給他'）
>>>    不賣票給他 ＜--執行結果


如果想再加入更多的判斷，可以再加上否則如果的 elif 的關鍵字。

>>>age = 70
>>>if (60 <= age):
           print('票價為200元')
>>>elif (18 <= age):
           print('票價為400元')
>>>else:
           print('不賣票給他')
    票價為200元＜--執行結果
