

變數的命名規則

雖然變數可以自由命名,但不是所有文字都能用在變數名稱中。幫變數命 名須符合 Python 的命名規則:

名稱中只能包括:數字、大小寫英文字及_底線,雖然可以用中文,一般 不建議。

名稱開頭第1個字不能是數字。

不能使用 Python 的「保留字」(後面會說明什麼是保留字)。
