tuple 是不可更改的，所以經常被當作字典的key來使用（串列則是不行）。

因為，字典，需要很有效率的使用key，來存取資料。
Python就規定，不能用可變更（變動）的內容，作為字典的Key。

例如：
diary = {} <--建立空字典

key = ('kamata', '08-01') <--建立不可變更的tuple，就是使用（）括號就對了。

diary[key] = '70kg' <--以key為變數［鍵］，'70kg'為［值］，填入字典中。

print(diary)
{ ('kamata', '08-01'):'70kg'}
