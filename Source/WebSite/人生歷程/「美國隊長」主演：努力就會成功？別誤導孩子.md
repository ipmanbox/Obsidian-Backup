
# 「美國隊長」主演：努力就會成功？別誤導孩子


【大紀元2025年03月22日訊】（大紀元記者高杉編譯報導）許多父母都教育孩子：只要努力奮鬥，就能實現夢想。然而，這種說法往往忽略了運氣的作用。好萊塢2025新片《美國隊長：勇敢新世界》的主演安東尼‧麥凱（Anthony Mackie）就表示，單純強調努力就能成功，而忽視運氣的因素，是對孩子的一種誤導。

成功是上天所賜
今年46歲的麥凱近日在做客「The Pivot Podcast」節目時坦言：「我們對孩子們撒了謊。」他指出，父母常告訴孩子：「只要積極努力，就能成功……」並宣稱「只要努力就會有回報」。但麥凱認為，這並不完全正確。因為大多時候，成功是被上天「賜予」的，而非單純靠自己努力「賺來」的。


成功需要運氣
麥凱的演藝生涯就印證了這一點。在2014年《美國隊長2：冬日戰士》中飾演山姆‧威爾遜之前，他已演戲十餘年。這個新角色被視為他事業的突破。自2001年從茱莉亞音樂學院畢業後，他一直在戲劇和電影屆裡積累經驗，參演了包括2008年的《拆彈部隊》等影片。然而，在好萊塢的激烈競爭中，他始終難以出頭。

他透露說，在獲得這個突破角色之前，自己投入了大約上萬小時的訓練，還曾主動給漫威高管寫信，表達出演意願，但從未見效。而最終憑藉著運氣，等來了機會的降臨，他與羅素兄弟會面，獲邀參演新片。終於得以從「龍套」小角色成長為大片主角。

麥凱並非唯一看重運氣的人。美國知名投資人、坐擁41億美元財富的馬克‧庫班（Mark Cuban）2023年對男士雜誌《智族》（GQ）表示，那些聲稱能白手起家、從零開始，靠自己的努力就成為了億萬富翁的人，往往都是在誇大其詞，因為遇到合適的時機、遇到好運氣至關重要。他認為，若早出生幾年，自己就不可能會有今日的成就。顯然，運氣和人脈、能力同樣重要。

巴菲特的「最佳拍檔」查理‧芒格（Charlie Munger）2018年在密歇根大學演講時也強調，即便你是房間裡最努力、最優秀的人，你的成功也離不開運氣。他坦言，自己一生中並未刻意追逐財富，卻意外獲得成功。


「好運的人」什麼樣？
那麼「好運的人」都是什麼樣的呢？心理學家理查德‧威斯曼（Richard Wiseman）在《運氣因素》一書中總結說，那些獲得好運的「幸運兒」都有以下的特質：

1. 他們一直都很樂觀。即使身處困境，這些「有好運」的人也會認識到，事情「本可以更糟」。而悲觀的人會自暴自棄，將所有運氣都擋在門外。

2. 他們不會拒絕新機會。被稱為運氣好的人會表現出開放性和適應性，這使他們總是能夠結識新人和建立新聯繫。而新機會就藏在這些新的接觸、新的關係之中。

3. 他們依靠直覺作決定。花太多時間來思考和權衡會導致「優柔寡斷」、錯失良機。被稱為好運氣的人更傾向於「直接作出決定」，他們更相信自己的直覺，所以經常能夠奪人先機地抓住新機會。

4. 他們能從挫折中迅速恢復。失敗從來不可避免，但在事情不如預期時，他們仍會保持「未來會更好」的積極心態，讓失敗和挫折帶來的負面影響降到最低，擺脫「衰運」的掌控。「衰運」之後自然是「好運」。

如何獲得好運氣？

大多數人都沒有仔細想一想，究竟什麼是「運氣」？什麼是「好運」「厄運」？是一種什麼樣的觸發機制，來決定一個人有好運，而另一個人有厄運呢？實際上，在幾千年的中華文明智慧中，早已有了非常透徹的解釋。

中國有句古話：「善有善報、惡有惡報」。就是說，想要在未來獲得好運氣，就要「積德行善」。

不過，紅塵之中迷霧重重，很多的善報、惡報並不會立即出現，而是在更長的時間段之後才顯現，甚至按照佛家的輪迴理論來說，會在下一世中得善報、惡報。所以，就出現了令很多人難以相信和理解的情況：憑什麼有些人的運氣會這麼好，而有些人則是無論如何付出和努力，最終都一事無成。

但不管相信與否，「善有善報、惡有惡報」都是古老文明的智慧結晶。那些希望在未來獲得好運氣的人，可以先從「積德行善」開始改運。而且在教育子女時，在敦促他們要不斷努力的同時，也不要忘記講述關於「善惡有報」的古老智慧。不然，就像麥凱所提醒的，就是在誤導孩子。
